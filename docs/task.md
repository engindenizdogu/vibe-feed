  Generation Flow (Detailed)                                                                                                                                                                                                                         
                                                                                                                                                                                                                                                     
  1. User submits prompt                                                                                                                                                                                                                             
       ↓                                                                                                                                                                                                                                             
  2. Backend creates App record (status: pending)                                                                                                                                                                                                    
       ↓                                                                                                                                                                                                                                             
  3. Job queued → WebSocket: "Generation started"                                                                                                                                                                                                    
       ↓                                                                                                                                                                                                                                             
  4. Prompt Analyzer Agent:                                                                                                                                                                                                                          
     - Determines app type (web app, game, tool)                                                                                                                                                                                                     
     - Selects tech stack (React, vanilla JS, etc.)                                                                                                                                                                                                  
     - Estimates complexity                                                                                                                                                                                                                          
       ↓                                                                                                                                                                                                                                             
  5. Code Generator Agent:                                                                                                                                                                                                                           
     - Generates complete source code                                                                                                                                                                                                                
     - Creates package.json, index.html, etc.                                                                                                                                                                                                        
     - WebSocket: "Code generated (60%)"                                                                                                                                                                                                             
       ↓                                                                                                                                                                                                                                             
  6. Deploy Manager Agent:                                                                                                                                                                                                                           
     - Creates Daytona workspace                                                                                                                                                                                                                     
     - Pushes code to workspace                                                                                                                                                                                                                      
     - Triggers build                                                                                                                                                                                                                                
     - Waits for healthy status                                                                                                                                                                                                                      
     - WebSocket: "Deploying (80%)"                                                                                                                                                                                                                  
       ↓                                                                                                                                                                                                                                             
  7. Screenshot service captures thumbnail                                                                                                                                                                                                           
       ↓                                                                                                                                                                                                                                             
  8. App record updated (status: live, live_url, thumbnail)                                                                                                                                                                                          
       ↓                                                                                                                                                                                                                                             
  9. WebSocket: "Complete" + app data
